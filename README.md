Sistema de Gestión de E-commerce GO 

Para el Aprendizaje autónomo 1, se realizará un sistema de gestión e-commerce mediante una programación funcional en GO para una tienda de ropa y moda, el cual contará con 4 módulos siguientes:

1. USUARIOS
2. PRODUCTOS
3. COMPRAS
4. PAGOS Y ENVÍO

Objetivo: Desarrollar un Sistema de Gestión de E-commerce para una tienda de ropa que permita administrar usuarios, productos, ventas, pagos y envíos, con el fin de optimizar los procesos de comercialización, mejorar la experiencia de compra de los clientes y facilitar la gestión administrativa de dicho negocio.
