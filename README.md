**********************************************   Sistema de Gestión de E-commerce GO    ***************************************************

Para el Aprendizaje autónomo 1, se realizará un sistema de gestión e-commerce mediante una programación funcional en GO para una tienda de ropa y moda, el cual contará con 4 módulos siguientes:

1. GESTIÓN DE USUARIOS
2. GESTIÓN DE PRODUCTOS
3. GESTIÓN DE COMPRAS
4. GESTIÓN DE PAGOS Y ENVÍO


*************************************************************************
Objetivo:

Desarrollar un Sistema de Gestión de E-commerce para una tienda de ropa que permita administrar usuarios, productos, ventas, pagos y envíos, con el fin de optimizar los procesos de comercialización, mejorar la experiencia de compra de los clientes y facilitar la gestión administrativa de dicho negocio.


---------------------------------------------------------------------------
Funcionalidades:

Registrar usuario

Iniciar sesión

Consultar usuarios

Registrar producto

Consultar productos

Actualizar producto

Eliminar producto

Agregar al carrito

Generar pedido

Registrar pago

Consultar envío

*************************************************

***** Puntos importantes


1. Registro de nuevo usuario

2. Se clasifica como admin o cliente

3. Se despliega un menú
 
  3.1. Menú para cliente
  
  3.2. Menú para administrador

4. Compra de productos

5. Venta, pago y envío

********************************************
